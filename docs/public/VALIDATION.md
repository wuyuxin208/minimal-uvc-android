# 验证范围

应用版本：1.3.2 / versionCode 8。验证日期：2026-10-09。

## 已完成

- JDK 17、Gradle 8.2.1、AGP 8.2.2、Kotlin 1.9.22 下构建成功。
- 59 项 JVM / Robolectric 测试通过；Lint 0 错误、4 项提示。
- Huawei DBY-W09，鸿蒙 4，Android API 31：覆盖安装、启动和长按菜单通过。
- 真机合成 GPU 输入：2560×1600，初始提交约 60.1fps；同一生产端跨十次实际 Home / 返回恢复，后台消费输入且不提交到屏幕。
- 用户接入真实采集卡后，手动确认返回桌面再打开能够恢复视频。

合成 GPU 测试绕过 USB、Native 解码及 HDMI 输入，不能用于证明采集卡性能。用户手动复测不计为十次自动真实 USB 回归。

## 尚未完成

- 真实采集卡十次前后台切换、十次拔插及连续三十分钟稳定性测试。
- 多采集卡、其他鸿蒙型号和新版 Android 兼容性验证。
